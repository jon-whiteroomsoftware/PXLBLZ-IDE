# Palette doctrine

Color is part of the visual system, not decoration added after it.

## Roles

- **Black is space.** Use it to make silhouettes legible, separate voices, create anticipation, and give energy somewhere to expand.
- **White is impact.** Reserve it for hits, inversions, edge punctuation, revelation, or convergence.
- **Main colors carry identity.** Use one or two saturated hues with an obvious hierarchy.
- **An intruder breaks familiarity.** Introduce one contrasting palette during a structural turn, then remove it so the main identity can return with force.

Black and white are light and shadow rather than entries in the main color count. In Redline, red carries pressure, black supplies the world, white marks impact, and cyan appears once as the intruder.

## Selection rules

1. Demand strong luminance or hue contrast at the intended physical brightness.
2. Keep the main list short enough to name from memory.
3. Assign each hue to a visual or temporal function before implementation.
4. Avoid continuous rainbow cycling unless spectral order is the concept.
5. Test ordinary frames between accents.
6. Use a low emissive floor only when physical spacing would erase intended dark color; preserve true black where the composition needs void.
7. Return from an intruder decisively. Indefinite blending turns exception into ordinary drift.

Fire is a useful analogy for intensity: familiar base, concentrated light, irregular negative space, and rapid local change. Borrow that hierarchy rather than copying an orange-yellow gradient.
