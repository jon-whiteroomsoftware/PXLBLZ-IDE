# Checked v2 recovery from refused preparation

`captureShowStageEditV2` captures a frozen authored record and data-only Pattern,
Map, Library and profile payloads independently of source compilation. Its
`inputCapture` is qualified only after complete v2 structural/domain validation
and trusted Stage map identity/dimension/resolver-context qualification. Invalid
capture remains a distinct refusal. Original record/dependency references identify
eligibility; candidate preparation consumes captured semantic payloads. A bound
map resolver remains functional context, with captured map metadata. This does
not establish general sample/position independence or clone resolver closures.

`prepareShowStageV2` retains its ready/empty/refused public contract. A source or
adapter refusal can coexist with qualified edit inputs; playback and export stay
unavailable. `prepareShowStageFromCapturedInputsV2` validates and prepares the
changed record against those same inputs. There is no failure-string whitelist,
recovery flag, placeholder runtime, source substitution or ignored saved control.

The private checked admission core accepts only registered typed intents. The
six-intent `admitShowV2PilotPropertyEdit` wrapper takes explicit persisted Show or
Group-definition ownership and returns the exact fourteen affected collections,
owner/admission refusal partition and receipt-aware settlement. Pure-owner refusal
and actual no-op write nothing. Qualified source-refused preimages can recover
only to a fully ready candidate. Existing ready/empty capability partitions remain
unchanged, including typed Create's explicit empty-to-ready partition. No new
content deletion or cleanup behavior is introduced.

Admission rechecks record, revision, provider, route and trusted dependency
identity immediately before one existing history/adoption/save operation. The
local receipt cannot interrupt persistence. Save failure and external supersession
retain the existing rollback and completion behavior. Legacy callers carrying an
already-ready/validated-empty prepared capture retain compatibility; a refused
capture without qualified inputs has no recovery eligibility. An explicit invalid
capture always refuses a changed result.

The opt-in route constructs one qualified capture. Existing Layer controls may
submit typed edits from that context; complete candidate eligibility still decides.
The visible recovery proof removes an unused overlay from a valid independently
sampled multi-Zone Show, recovering the already-supported flat preparation path.
The existing artifact control is available only for ready preparation. The
30-second proof uses the trusted stock plane for its 2D split samples; generic
strips retain their existing empty sample coordinates.
No temporary recovery control, arbitrary candidate callback, compiler/schema/domain
expansion, second save queue or production route cutover is added.
