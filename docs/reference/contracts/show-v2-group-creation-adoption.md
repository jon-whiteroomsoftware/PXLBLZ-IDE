# Native v2 Group creation adoption

The opt-in Show route exposes ordinary Clip checkboxes, explicit attached
Transition checkboxes, a Group name and Create Group. The panel shows each
Pattern name, Zone, Layer and exact millisecond range. Group children remain
read-only occurrence projections; they are never selectable persisted Clips.

`buildShowV2GroupCreationEditorModel` presents ordinary owners and attached or
explicitly selected Transitions. `planShowV2GroupCreation` forwards exactly the
user's selection and computes the minimum selected start. One supplied
`newPersonalContentId` allocation creates each local identity. The complete
identity maps preserve existing owner namespaces, including nested key scope.
The model never expands chains, chooses another origin or infers missing IDs.

`admitShowV2PilotCreateGroup` registers only the typed existing creation intent
in the private checked-admission core. It retains the pure owner's fifteen
explicit affected collections, including `hoistedInstanceIds`. Qualified
immutable assets, record/provider/revision/route/dependency checks, one candidate
preparation and one existing adoption/history/save remain required. No arbitrary
candidate, new save queue, runtime writer or compiler policy is introduced.
See [Group edits](show-v2-group-edits.md),
[prepared recovery](show-v2-prepared-recovery.md) and
[history/persistence](show-state-history-persistence.md).

The pure owner decides lossless representation and returns its typed refusal.
Refusal performs no write/history and retains selected drafts. Successful current
completion clears selection and displays the persisted occurrence through the
existing timeline. A pending operation blocks duplicate submission; receipt-aware
completion suppresses obsolete feedback. Current save failure restores durable
record data/history through the existing store and retains drafts for an explicit
retry. That store's validated fallback is a clone, not the original object.

## Layout and limits

The panel uses the existing zinc palette, small headings/labels, native
checkboxes and existing outline Button. Whitespace separates selection, name and
action; no nested cards, decorative text, origin control or occurrence actions.
At narrow widths, identity labels wrap and controls remain keyboard-operable.

```
Groups
Clips
[ ] Voice · Main / Overlay · 2000–3000 ms
[ ] Voice · Main / Overlay · 4000–7000 ms
Transitions
[ ] crossfade · verse-transition
Name [Verse                         ]
[Create Group]
```

This adoption slice supports the existing lossless owner, including a complete
single-Layer pair, shared runtimes/global animation and Restart. Partial chains,
outside-local activation and other existing-format limitations refuse atomically.
It adds no Group occurrence editing, production cutover or compiler support.
