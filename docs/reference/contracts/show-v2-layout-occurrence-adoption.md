# Opt-in Layout occurrence authoring

The native pilot selects persisted Layout occurrence IDs and delegates existing
select-layout, move, make-unique and remove intents to `editShowLayoutIntervalsV2`.
The initial switch remains at zero. Existing definitions are selected explicitly;
Make Layout Unique supplies a fresh definition ID and explicit name. No definition
geometry, incoming-transfer settings or authored times are inferred by the UI.

## Layout and interaction

The inspector follows the existing zinc editor fields and buttons, with no new
panel chrome or decorative text:

```text
Layout occurrences
Occurrence [name · start–end ms · ID]
Layout [existing definition]   Apply Layout
Switch (ms) [exact authored time]   Move switch
Unique name [name]
Make Layout Unique   Remove occurrence
```

Definition identity and persisted occurrence identity remain separate. Native
select and NumberField controls support keyboard navigation and exact integer
owner admission; the UI does not round or clamp authored times. The first switch
cannot move. Meaningful track/transfer removal and unavailable-Zone changes retain
the existing observable atomic owner refusal.

## Checked adoption

`admitShowV2PilotLayoutOccurrenceEdit` accepts only the four closed typed intents,
using the same immutable qualified capture, record/revision/provider/route and
trusted dependency checks as other native pilot edits. It returns exactly the six
existing Layout affected collections. Changed candidates fully prepare before one
existing history/adoption/save; no-op/refusal produces no timestamp, history or
write. Ready/empty capability follows the existing discipline; this wrapper grants
no arbitrary compiler-refusal bypass or empty-to-ready transition.

Saved completion follows the local adoption receipt through parent capture
replacement. Removal clears selection; other actions retain the same occurrence.
Current save failure restores the store/history while retaining the explicit
placement draft for retry. Superseded completion cannot overwrite selection/status.
One pending operation guard prevents concurrent submissions from this inspector.

## Preservation and proof

Definition uniqueness changes only definition identity and occurrence reference;
Clips, Pattern runtime identity, controls, global animation and held Group time
remain intact. Moving a switch changes adjacent coverage only. Occurrence-owned
tracks keep their authored global times and refuse if outside the new interval;
transfer windows/attachments and complete spanning contribution availability are
validated by the existing owner. Removal extends the predecessor or promotes the
next occurrence to zero without content cleanup or implicit Restart.
