# Native v2 artifact qualification

The opt-in pilot qualifies the same ready `ShowPreparedStageBundleV2` displayed
by Stage. `qualifyShowV2PilotArtifacts(bundle, options)` delivers `.pxlshow` bytes,
native `.epe` text/source and the ordinary import-planned native record. It does
not prepare, compile, directly lower or fabricate a legacy Show.

At capture start the Stage factory clones and recursively freezes the authored
record and data-only Pattern, Map, Library and Controller profile assets.
Original references identify eligibility only. Map resolver closures are resolved
synchronously into existing Stage presentation, never serialized as assets.

Before its first await, qualification copies scalar export options and constructs
the native Show file bundle and native EPE envelope from the owned record/assets
and exact compiled code. Serialization, versioned parse and collision planning
continue using those same snapshots. Authored holds, bindings, tracks, keys and
dormant Markers survive file reopening. Existing import policy may rename or
remap the applied imported record. Preview readiness does not bypass missing
portable dependencies, including custom maps and dormant authored definitions.

The pilot starts qualification from its memoized ready bundle. Record, route,
Pattern/Map/Library/profile identity, provider replacement and a newer operation
retire pending status publication. Stale success and error completions publish
nothing. Qualification makes no adoption, history or save call. Empty content
has no runtime or qualification capability and remains editable/saveable through
its separate checked admission seam. Marker admission and Transition UI are
unchanged; no default route cutover occurs.

Consumer tests reopen exact authored files and delivered native source, compare
Fast/Precise frames and shared state across holds, full Restart and animated
Layout boundaries, and retain independent quadratic oracles. Precise state
checks use binary-safe 125ms steps; float tolerances describe existing 16.16
arithmetic, not arbitrary-ms exactness. Delayed serialization tests mutate caller
records, source, controls, maps and options while awaiting, proving snapshot
ownership. The Stage sample-from-position behavior remains the inherited residual
documented in [the prepared Stage contract](show-v2-prepared-stage.md).
