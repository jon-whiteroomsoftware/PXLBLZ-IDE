# Native persisted Property editor

The [canonical Scene retirement specification](../../plans/scene-retirement-specification.md)
§§4/6/9/12 and [pure Property edits](show-v2-property-edits.md) govern this thin
editor. Explicit persisted Show scope offers nine target families; Group-definition
scope offers seven local families and affects every linked occurrence. Definition
selection is independent of ordinary Clip selection. Materialized IDs are read-only
consumer/eligibility information, never writable aliases.

## Targets and authored drafts

Owner, persisted track and key selection starts unselected. A new track supplies an
explicit target, activation, at least two ordered time/value/easing keys and complete
fresh caller identities. A new key likewise supplies an ordinary complete key.
Each required identity allocates once after valid complete drafts, without retries.
Track IDs are persisted-owner scoped and key IDs are track scoped. The pure owner
retains final identity/conflict/complete-candidate validation.

Raw numeric fields do not clamp or substitute defaults for blank/nonfinite values.
Track updates contain only dirty target/activation fields; key updates contain only
dirty time/value/easing fields. Activation never shifts/crops authored keys. Merely
opening/applying a key preserves custom structured easing and retained descriptors.
Explicit endpoint/easing edits use existing reauthoring, including affected neighbor
kernels; the panel explains that consequence without accepting descriptor patches.
Custom Bezier Y coefficients use the validator's full finite domain rather than
preset slider bounds. Every curve-dependent coefficient/direction/position remains
explicit, including Steps and Hold equality semantics.

Instance slider choices require the exact captured bundled source export and an
existing finite authored scalar baseline. They never mint discoverable default
control values. Group choices inspect all authoritative linked runtime bindings;
dormant hoisted defaults retain top-level source/payload authority. Shared consumers
include ordinary and Group Clips. Clip Effect choices retain exact ID/kind/numeric
parameter across every held span intersecting requested activation, including
inherited incoming/outgoing contribution through the existing contribution helper.
Layout and Show-global targets remain excluded from definition scope.

## Adoption boundary

The panel sends only a closed typed `propertyOwner` and authored intent. The Route
binds `admitShowV2PilotPropertyEdit`; no caller candidate or transformation is accepted.
The shared qualified-input capture/admission owner controls final prepared eligibility,
provider/current/receipt/lifetime checks, all fourteen affected collections, one
optimistic adoption/history/save, and atomic refusal/no-op/rollback. The panel keeps
pending submissions locked and suppresses obsolete completion feedback. Engine
capture inputs/assets and runtime identities remain provider-free.

Source-dependent eligibility and named compiler refusals stay at final admission.
A qualified preimage whose current preview is unavailable may be repaired only if
that shared owner prepares the complete candidate successfully. Invalid captures
remain unavailable; neither source assets alone nor a component callback bypasses
qualification. The recovery/capture prerequisite is a separately reviewed slice.
