# Stable exact-duration Retry

The diagnostic activity can retry a single resolved Clip duration after a live
conflict, cancellation, timeout or save rollback. The original broad identity
remains intact while a fresh private transaction re-executes the exact command.
The [candidate contract](../../contracts/agent-candidate-application.md#stable-diagnostic-resize-retry)
defines eligibility and the remaining limits.

The focused bridge, admission and overlay suites prove executed ordinal binding,
complete fresh-state execution, linked retries, malformed delivery becoming
terminal, foreign-envelope preservation, property-order-independent comparison,
ordinary save rollback, explicit activation and composer/keyboard preservation.
The first binding, private retry, admission and overlay tests each failed before
their implementation. One initial test process could not create Vite's cache in
the sandbox; the actual red runs used worktree access.

The B5 browser sequence uses five synthetic personal Shows. Each first request
targets A at 0 seconds, then a manual edit moves A to 12 seconds behind B at 8
seconds. The original candidate conflicts. Explicit Retry retains A, preserves
the unrelated composer and requests its original exact eight-second duration.
Desktop and narrow cases compare complete visible/durable records and PATCH
bodies, download/reopen the real Show file, and Undo back to the manual move.
Deletion refuses without replacement; Dismiss retains history without a request;
cancellation through the existing diagnostic API while thinking prevents the
delayed retry candidate from applying. This does not introduce or qualify a
visible thinking-state Cancel control.

The first browser probe exposed an ambiguous test selector because both Clips
use CometLoom. The corrected selector uses the rendered logical Clip identity.
The five-case uncommitted-source run passed in 37.2 seconds (41.5 seconds total).
Committed-source proof and final coordinator checks are recorded in the handoff.

All five scoped temporary faults were detected by assertion failures and the
source was restored: see [fault results](faults.json). The focused seven-suite
run passed 116 tests before the committed browser pass. Full committed-tip suites
and native candidate review remain the coordinator's gates.

No domain term changes, production Agent UI, Controller changes or compiler
changes are introduced. CONTEXT, the Feature Guide and Technical Reference keep
their existing ownership descriptions; this specialized contract owns the new
diagnostic behavior. Issues #949 and #950 retain their remaining scope.
