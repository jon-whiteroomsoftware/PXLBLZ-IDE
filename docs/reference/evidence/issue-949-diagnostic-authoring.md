# Diagnostic authoring validation (#949)

The local diagnostic service selects the existing authoring validation policy.
Incomplete Installation coverage and Portable capability mismatch no longer
prevent an unrelated valid edit. Structural, identity, metadata and final
candidate validation still refuse invalid edits; delivery gates remain separate.
Browser capture projects flat Shows using exact loaded Pattern sources through
the existing composition projector. It writes nothing until an accepted edit;
the ordinary store keeps the original flat record as the Undo base.

## Evidence

- Service tests traverse real `runUtterance`, MCP and typed completion: missing,
  overlapping, above-output and negative integer ranges; Portable mismatch;
  malformed owners/endpoints/composition; new broken references; unavailable
  flat source/control metadata; unchanged missing personal composition; no-op;
  final refusal, one bounded repair and private rollback.
- Admission tests cover exact personal source projection, asked/refused/no-op
  completions without history/write, one successful adoption and original Undo,
  missing flat source refusal, unusual imported cell IDs, and Pattern/Library/Map
  replacement-and-restore invalidation.
- Browser H drives the real scripted service with a personal Pattern calling a
  personal Library. The POST carries composition, one PATCH persists the complete
  expected record, the downloaded `.pxlshow` reopens identically, and one Undo
  restores the original flat Show and exhausts history. No console errors.
- Browser SA retains its four clean/cancel/save/clear-plus-pointercancel cases,
  now starting with incomplete physical coverage. Scripted resize waits behind
  dirty drafts, cancellation permits one adoption, and manual Save makes the
  broad response stale. Complete visible/durable/exported records agree and Undo
  exhausts history. `.epe` remains disabled. The clean physical-range edit uses
  the existing direct adapter because the grammar has no physical-range command.
- All seven fixture baselines remain unchanged with exact fixture sources; no
  accepted hash was rewritten. Personal-Library `.epe` fixture export still lacks
  Library transport and reports its existing error.

The old service policy fault fails four physical-coverage acceptance cases.
Bypassing final authoring validation fails the final new-dependency refusal case.
Both faults were restored before the passing service run. The initial personal
browser case failed with an unprojected POST; exact browser projection resolves
that failure without relaxing missing-source validation.

## Limits

Negative range artifact tests use the explicit internal preserving importer;
default product import still normalizes physical ranges. No paid inference,
hosted endpoint, production Agent panel, new metadata transport, narrower model
context, arbitrary private intermediate batch, or Controller delivery is qualified.
This supersedes the initial SA report's valid-coverage-only scripted limitation.
