# #1210: constant Effect parameter binding results

The compiler omits writes only when every routed placement resolves an Effect
parameter to its declaration value and no collected animation targets that
Effect ID and field. Declarations, dynamic and absent-Effect identity resets,
matrix writes and animation order retain their existing behavior. Non-routed
recipes retain their emission; `effectParameterHoisting: false` restores the
counterfactual independently of other compiler options.

All 46 native stock Shows reopened through actual `.pxlshow` and EPE bytes.
Exact finite RGB comparisons passed independently in Fast and Precise for
36,488,112 channels, 81,950 Stage points and 3,698 named times per mode.
Nineteen Shows shrink, with generated source totaling 1,354,208 → 1,282,997 B
and delivered source totaling 1,456,009 → 1,384,798 B (71,211 B saved).
After Hours saves another 2,189 B and Cloudburst another 6,558 B on top of
their existing record workaround. Installation Composition saves 5,632 B
without that workaround. Twenty-seven Shows are unchanged.
