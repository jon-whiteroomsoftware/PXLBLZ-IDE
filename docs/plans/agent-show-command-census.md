## Reading the census

`V` means `src/engine/showCommands/`; `G` means `src/agent-harness/grammar/operations/`; `E` means `src/components/ShowEditor.tsx`. File:line references identify the inspected source. Rows name both registry spellings, including merged and excluded entries. A dash means absent from that registry. A real manual handler is evidence of a surface, not proof that its entire schema equals the grammar. All retained rows inherit fixture A below and their named family fixture. The tables are the finite shipping manifest; the manual-only residual inventory is explicitly outside automatic catalogue expansion.

## Common fixture obligations

These are required future checks, not executed results. Each retained operation has one accepted fixture and one typed-refusal fixture from its row plus the common A obligations; table-driven enumeration must fail when a registry entry has no disposition or fixture ID. Freeze the source names, canonical name, schema, owner, actual manual adapter and fixture IDs in a checked manifest. A schema leaf coverage report or broad `touches` path does not establish command support.

- **A — transaction/admission:** Use a personal Show with two Zones, Main plus two overlays, two Scenes, separate and shared Pattern instances, and an unrelated pre-existing missing Pattern reference. Accepted change preserves immutable input, stable referenced identities and the complete valid authored projection; real route adopts once, records one history entry and saves once. Reopen `.pxlshow` and compare the whole document modulo declared generated IDs/bookkeeping. Undo removes only this operation while preserving an intervening independent manual edit. Refusal compares complete current document/history/provider calls: no attributable change. A valid already-satisfied request has no revision/timestamp/history/provider change; a no-op before/after a changed step does not abort the batch; wholly no-op batch never adopts. Missing/invalid/unsupported identity returns remain refusal. Duplicate operation delivery returns the original result without rerunning.
